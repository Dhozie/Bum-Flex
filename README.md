# Bum Flex

A responsive one-page website for Bum Flex.

## Features
- Responsive design
- Product/cart functionality
- User login
- Google sign-in
- Contact form
- Supabase integration
- Mailgun email notifications

## Technologies
- HTML
- CSS
- JavaScript
- Supabase
- Mailgun

## How to run
Open index.html or run the project with a local development server.

## Important
API keys and secrets should never be committed to this repository.
